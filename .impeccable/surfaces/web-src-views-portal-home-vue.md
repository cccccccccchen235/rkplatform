## Direction contract

**THESIS** — 首屏是一面书架：20 个科目各是一根书脊。它拒绝的默认编排是「功能卡片网格」——那种版式把每门课渲染成同等大小、同等可点、同等可期待的方块，于是「这门课现在到底有没有东西可练」这个唯一要紧的问题被抹平了。书架把这件事摆在明面上：20 根脊里只有 3 根是蓝框的（软件设计师、系统架构设计师、信息系统项目管理师）。

**OWN-WORLD** — Element Plus 变量体系：主色 `#2a72c2`（运行期覆盖其默认 `#409eff`）、正文 `#303133`、底 `#f5f7fa`、描边 `#dcdfe6`，圆角 2/4/8；只覆盖颜色变量，不换皮、不改组件结构。书脊是纯色块 + 1px 描边，零纹理、零拟物投影；层板是唯一允许的实体感，且只来自一条 1px 实线，不来自渐变或阴影。脊上竖排科目名，脊脚横排代码与满分，数字等宽对齐。

**STORY** — 访客一眼得到两件事：这门考试共 20 个科目、分三级；以及只有 3 门现在真的能练。他不会把「点进去是空的」误当成自己找错了地方。接下来他取下某一本，进入该科目的详情。

**FIRST VIEWPORT** — 顶栏之下直接是三层通栏书架，无卡片容器包裹。上层高级 5 本、中层中级 11 本、下层初级 4 本，**全部等高 160px**（160px 按"三层书脊在 1280×800 内同时可见"定）。层级由层标签（高级 / 中级 / 初级）说明；脊高不再编码数据。脊宽 88px；蓝框（`#2a72c2` 实线描边）= 已印的 3 本（大纲与题库已完备），其余 17 本为 `#f5f7fa` 灰脊 + `#dcdfe6` 虚线框——这是架上**唯一**一处图形编码。书脚一行给出「编号 + 卷面满分」，考期在取下来的抽屉里。主操作是点击书脊本身，没有独立按钮。

> **2026-10-02 修订**：原 brief 把「脊高 = 卷面满分」与「顶端色带 = 考期」写进方向契约。渲染实测发现两者都不挣得位置（脊高只重复了层级——每层内部高度本已相同；6px 色带与蓝框同色同位相撞），经委托方裁决移除。理由与证据见 `docs/26` 与 `DESIGN.md` 的 Overview。

**FORM** — 书架书脊。surface roll seed key `a13ea8a1`，dealt 索引 7（同手另两张：索引 3「考期总表」领牌、索引 2「寻路站牌」）。在我自己的接地候选序里它排第 2：总表在「20 个一个不漏」上更强，书架在「哪本现在能读」上更强，而首页要回答的是后者。

**FINISH** — unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
