## 3. 字段定义（13 个全部必填）

| 字段 | 类型 | 取值 / 说明 |
| --- | --- | --- |
| `subjectId` | string | **固定 `"6"`**（软件设计师） |
| `outlineId` | string | **第 8 节附录里的章节 ID**，必须原样照抄，**不要自己编造** |
| `questionType` | string | **固定 `"SINGLE_CHOICE"`**（本批只出单选题） |
| `stem` | string | 题干，Markdown + KaTeX 公式 |
| `stemFormat` | string | **固定 `"MARKDOWN"`** |
| `options` | array | **恰好 4 个**：`[{"key":"A","content":"…"},{"key":"B",…},{"key":"C",…},{"key":"D",…}]`，`key` 只能是 `A`~`F`（本批用 A~D） |
| `correctAnswer` | string | 正确选项的 key，**单个字母**，如 `"C"` |
| `analysis` | string | 解析，Markdown；**必须含推理过程**（为什么选它、其余为何不选） |
| `difficulty` | integer | **1~5，1 最易、5 最难**（分布见第 7 节） |
| `knowledgePoints` | array | `[{"name":"知识点短语"}]`，**至少 1 个、最多 5 个**；用中文知识点短语（如"分页存储管理"），**不要用章节标题** |
| `sourceType` | string | **固定 `"AI_GENERATED"`** |
| `sourceLicense` | string | **固定 `"SELF"`** |
| `sourceRef` | string | 形如 `"SD-01;outline=<该题的 outlineId>"` |

**可选字段**：`clientKey`，建议格式 `"SD-01#0007"`（文件名 + 行内序号），便于定位问题行。

## 4. 内容硬约束（违反会被导入器直接丢弃）

1. **恰好 4 个选项**，每个选项都要有实质内容；不得出现"以上都对/以上都不对"这类凑数选项。
2. **唯一正确答案**：必须只有一个选项正确；另外 3 个必须是**合理的干扰项**——来自同一知识点的常见误解（概念混淆、公式代错、量纲错误、参数顺序颠倒等），不得明显荒谬或与题干无关。
3. **题干必须是自包含的**：不依赖"如上图""见教材第 X 页""第 X 题"之类的外部引用；不得以"第 X 题"开头。
4. **题干长度**：去掉 Markdown 标记后，可见字符数在 **10 ~ 600** 之间。
5. **公式**：用 KaTeX，行内 `$...$`、块级 `$$...$$`；**不要用图片**。
6. **解析必须有推理**：说明推导过程与选项取舍，不能只写"故选 C"。
7. **知识点不超过 5 个**，且要与题目真正相关。
8. **难度要与题目实际匹配**：难度 1~2 的题不应含块级公式 `$$` 或超过 200 字；难度 5 的题不应短于 20 字。（难度与题干长度严重不符的会被标为"存疑"退回）
9. **同章节内不得出现重复或高度相似的题**：题干经归一化（去空白标点、转小写）后相似度达到 0.9 即判定重复。

## 5. 版权红线（最高优先级，违反即整体作废）

1. **严禁引用、复述、改写、影射任何历年试题、官方试卷、官方教材与辅导书的内容。**
2. 题干、选项、解析中**不得出现任何年份、考次**，**不得出现"真题""原题""试题""历年"等字样**。
3. 题目应为**依据考点独立命制**，而不是对任何已有题目的改写。
4. 不得凭记忆复现任何具体考题。

> 这几条是硬性合规要求。如果某道题你不确定是否与公开考题雷同，**换一个角度重新命题**，不要抱着"改一改就行"的想法提交。

## 9. 最容易被退回的原因（已知的坑）

| 现象 | 原因 |
| --- | --- |
| 整行被丢弃 | JSON 不合法：最常见是**未转义的反斜杠**（`$\log_2$` 必须写成 `$\\log_2$`）、字符串里有未转义的英文双引号 |
| 整行被丢弃 | 命中了版权红线词（年份 / 考次 / "真题"等） |
| 整行被丢弃 | 选项不足 4 个，或 `correctAnswer` 不在选项 key 里 |
| 整行被丢弃 | 题干去标记后少于 10 字或多于 600 字 |
| 整行被标"存疑" | 难度与题干长度严重不符（如标 `difficulty: 5` 但题干只有 15 字） |
| 整行被标"存疑" | 解析里没有推理过程（只写了结论） |
| `outlineId` 找不到 | 自己编了 ID 或抄错了数字——必须从第 7 节原样复制 |
| 中文变成乱码 | 文件未用 UTF-8 保存 |
